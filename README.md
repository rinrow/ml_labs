# Лабораторная работа №1. Линейная регрессия для `RiskScore`

Решение задачи прогнозирования кредитного риска `RiskScore` только линейными
моделями. Ноутбук `lab1_risk_score.ipynb` содержит полный цикл: очистку данных,
EDA, собственные scaler'ы и метрики, класс линейной регрессии с аналитическим
решением, GD и SGD, регуляризацию L1/L2/ElasticNet/Lp, K-fold и Leave-One-Out,
сравнение со sklearn, базовые модели и итоговую модель скрытых полос.

## Файлы

- `lab1_risk_score.ipynb` — выполненный ноутбук со всеми выводами и графиками.
- `submission.csv` — прогноз для `test.csv` в порядке `ID` из `ex.csv`.
- `data/` — исходные `train.csv`, `test.csv`, `ex.csv`.

## Результат

5-fold CV, два независимых разбиения:

| Метрика | Значение |
|---|---:|
| CV MSE | **18.2336 ± 0.0108** |
| CV MAE | 2.9638 |
| CV R² | 0.9386 |
| CV MAPE | 6.86% |

Требование `MSE < 19` выполнено с запасом.

## Идея модели

В данных видны две параллельные полосы. Используется модель

```
y = S(x) * (1 + kappa * b) + eps,   b in {0, 1},
```

где `S(x)` — линейная scorecard-оценка по пороговым индикаторам, а
`P(b=1|x)` — линейная вероятностная модель. Параметры находятся
EM-подобной схемой: жёсткие метки полосы, обычный OLS для `S` и `kappa`,
мягкие ответственности и взвешенный OLS, затем ridge-регрессия для `P`.
Итоговый прогноз — условное среднее `S(x) * (1 + kappa * P(b=1|x))`.

Все этапы обучения — линейная регрессия; нелинейные модели не используются.
